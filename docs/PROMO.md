# 技能架 · 宣传素材包（视频剪辑用）

> 用法：第 1–6 节是卖点库，第 7 节是可直接剪的脚本，第 8–9 节是标题/封面/录制动线，第 10 节是完整口播稿，第 11 节是事实边界。所有数字都按当前 0.5.4 版本核对过。

---

## 1. 定位与一句话

**主 Slogan**

> 一个窗口，管好你所有 AI Agent 的 Skills。

**备选 Slogan**

- 装一次，到处用。
- AI 技能的公共书架。
- 别再手动翻 `~/.xxx/skills` 了。

**不同长度的介绍**

- **10 字**：AI 技能的公共书架。
- **30 字**：把散落在 50 多款 Agent 里的 Skills 合成一个中文书架，一键装、一键删。
- **80 字**：技能架是一个跨平台桌面工具。它扫描你电脑里 50+ 款 AI Agent 的技能目录，把重复的合并成一张中文卡片；你能搜、能看说明、能一键装到多个 Agent，也能从 skills.sh 市场直接下载。
- **200 字**：如果你同时用 Claude Code、Codex、Cursor、OpenCode、WorkBuddy，技能大概率散落在十几个隐藏文件夹里：装了哪些、哪个是干嘛的、改过没有，全靠记忆。技能架把这些目录合成一个书架：自动扫描、合并去重、中文说明、模糊搜索；同一个技能一键复制或软链到任意 Agent，不想要了按 Agent 单独移除；内置 skills.sh 市场，热门/趋势/飙升榜都有中文摘要，一键下载；还可以用自己的大模型按任务挑技能。全本地运行，AI 可选，开源免费。

**最强主张（适合片尾/置顶评论）**

> 如果你同时用 3 个以上 AI 工具，这是目前最省事的 Skills 管理器。

> 在「中文 + 多 Agent + 本地优先」这个组合上，目前没有比它更完整的开源工具。

> 如果只能留一个 Skills 管理器，它应该是技能架。

## 2. 用户痛点（开场钩子素材）

### 场景 A：装了找不到
> 上个月装了个做 PPT 的技能，今天想用，忘了在 Claude 还是 Codex 里，翻了 5 个隐藏文件夹才找到。

### 场景 B：看不懂
> `SKILL.md` 全是英文，装完就忘；一百多个技能，名字长得差不多，根本不知道哪个能解决手头的事。

### 场景 C：装一次要复制五遍
> 同一个技能，Claude 装一遍、Codex 装一遍、Cursor 再装一遍；想删的时候又怕删错目录。

### 场景 D：不知道还有什么
> 只知道自己装过什么，不知道社区里还有什么能用的；skills.sh 全英文，翻半天。

### 场景 E：换电脑/重装
> 技能目录、套装、安装方式全没了，只能凭记忆重来。

**一句话总结痛点**

> AI 工具越来越多，技能越来越强，但**管理技能的方式还停留在手动翻文件夹**。

## 4. 功能全景（每条都给了「卖点 / 画面 / 口播」）

### 4.1 一次扫描 50+ 款 Agent

**是什么**：内置路径表，自动发现本机所有 Agent 的 skills 目录；目录不存在就标「未检测到」，不会误建；支持自定义目录和项目目录。

**解决什么**：不用记 `~/.claude/skills`、`~/.codex/skills`、`.cursor/skills`……也不用一个个翻。

**优越点**：
- 覆盖面广：57 个 Agent 名称、55 个独立目录；Claude Code、Codex、Cursor、OpenCode、GitHub Copilot、Gemini CLI、Antigravity、Windsurf、Cline、Warp、CodeBuddy、WorkBuddy、Qoder、TRAE、Kimi、Qwen、DeepSeek Harness、MiniMax、Doubao、Roo、Kilo、Continue、Goose、Amp、OpenClaw、QClaw、GitLab Duo 等。
- 国内工具覆盖好：WorkBuddy、Qoder、TRAE、Kimi Code CLI、Qwen Code、CodeBuddy、iFlow 等。
- 新增 Agent 通常只需在路径表加一行。

**可拍画面**：首页统计「X 个技能 / Y 个已检测工具 / Z 处安装位置」；卡片上的来源徽标；点右上角「刷新」。

**口播**：Claude、Codex、Cursor、WorkBuddy……一次扫完，全在这一个窗口里。

---

### 4.2 合并去重 + 多版本提示

**是什么**：同名技能在多个 Agent 里只显示一张卡，徽标标出装在哪些工具；内容不一致时标「多版本」。

**解决什么**：同一技能装 5 份，列表里出现 5 次；不知道哪份是最新的。

**优越点**：不是简单罗列目录，而是按技能名聚合；一个技能的状态一眼看清。

**可拍画面**：一张卡下面 `CodeBuddy / Cline / Warp / +3` 的来源徽标；「多版本」黄色标签。

**口播**：装了几个工具不重要，重要的是它只占你一张卡片。

---

### 4.3 中文简介：129 条，四段式

**是什么**：每条技能都有「一句话功能 / 什么时候用 / 优势 / 注意」；覆盖本机现有技能，不直接展示英文原文。

**解决什么**：英文 `SKILL.md` 看不快；装完就忘；不知道坑在哪。

**优越点**：
- 不是机翻一句话，是人工整理的能力、场景、优缺点。
- 详情页四段式，扫一眼就知道该不该用。
- 市场卡片同样只给「一句话功能 + 一行适用场景」，信息密度高。

**可拍画面**：卡片中文简介；点开详情，四段内容依次出现。

**口播**：每个技能都说人话：能干什么、什么时候用、有什么坑。

---

### 4.4 模糊搜索

**是什么**：支持中文、英文、路径、来源；多关键词 AND；包含匹配 + 子序列匹配；相关度排序；`/` 聚焦搜索框。

**解决什么**：技能名记不全；只记得「做 PPT」「小红书」这种用途。

**优越点**：搜「pdf」「小红书」「视频」「Claude」都能命中；不是只匹配标题。

**可拍画面**：输入「pdf」，结果实时收敛；按 `/` 光标跳进搜索框；`Esc` 退出。

**口播**：记不住名字没关系，记得你要干什么就行。

---

### 4.5 自动分类 9 类

**是什么**：按名称、简介、正文关键词三级加权，自动归入 9 个分类。

**解决什么**：技能一多就变成一锅粥；手动打标签坚持不了三天。

**优越点**：不需要维护标签；新技能自动落位；分类胶囊上直接显示数量。

**可拍画面**：分类胶囊切换；「全部 8 → 设计创意 3」的筛选过程。

**口播**：不用你打标签，它自己知道这是写代码的还是做设计的。

---

### 4.6 一键安装到多个 Agent

**是什么**：复制或软链接安装；Windows 自动尝试 junction，失败回退复制；支持多选后批量添加。

**解决什么**：同一个技能要在每个工具里复制一遍；软链在 Windows 上经常失败。

**优越点**：
- 勾选多个 Agent，一次装完。
- 安装方式可选，默认复制最稳；高级用户可用软链。
- 目标目录不存在会提示，不会到处乱建。

**可拍画面**：卡片「添加」→ 弹窗勾选 Claude、Codex、Cursor → 「已添加 3 个工具」Toast。

**口播**：勾三个 Agent，点一下，装完了。

---

### 4.7 按 Agent 单独移除

**是什么**：详情里列出每个已安装的 Agent，可以逐个移除；默认进废纸篓。

**解决什么**：想删又怕删错；只想从 Codex 删掉，不想动 Claude 里的。

**优越点**：移除粒度是「某个 Agent 的某一份」，不是一刀切；进废纸篓可恢复。

**可拍画面**：详情抽屉里 5 行 Agent，点某一行的「移除」；Toast「已移除」；文件消失。

**口播**：不想给谁用，就从谁那里删，别的工具不受影响。

---

### 4.8 套装（Preset）

**是什么**：把当前筛选结果存成套装，之后一键批量应用到多个 Agent。

**解决什么**：「做视频的一套技能」「写代码的一套技能」，每次换电脑都要重装。

**优越点**：套装保存的是你的工作流，不是单个技能；配合筛选，随时调整。

**可拍画面**：筛选「视频音频」→「保存当前筛选」→ 命名「视频工作流」→ 之后一键应用。

**口播**：把你的一套工作流存成套装，换电脑一键还原。

---

### 4.9 项目关联

**是什么**：选择项目根目录，自动识别项目内的 `.claude/skills`、`.codex/skills`、`skills` 等目录。

**解决什么**：项目级技能和全局技能混在一起；换个项目就找不到。

**优越点**：全局书架 + 项目书架分开看；项目内技能也能参与搜索和安装。

**可拍画面**：「项目」→ 选目录 → 项目技能出现在列表，带项目来源。

**口播**：项目自带的技能，也能一起管。

---

### 4.10 导入中央技能库

**是什么**：把本地技能文件夹复制到 `~/.skills-manager/skills`，单个或批量。

**解决什么**：技能散落在下载目录、桌面、Git 仓库；想统一存放。

**优越点**：中央库是「干净副本」，再从库里分发到各 Agent；市场下载也落到这里。

**可拍画面**：「导入」→ 选文件夹 → 中央库数量 +1 → 卡片出现。

**口播**：先把技能收进中央库，再决定装给谁。

---

### 4.11 配置备份

**是什么**：导出/导入技能目录、套装、安装方式；不包含技能文件本身。

**解决什么**：换电脑要重新配一遍；套装丢了。

**优越点**：文件小、可读、可版本管理；不会把你的技能内容打包上传。

**可拍画面**：设置里「导出配置」→ 保存 JSON；另一台机器「导入配置」。

**口播**：配置带走，技能文件不重复打包。

---

### 4.12 技能市场：三个榜单 + 9 分类

**是什么**：读 skills.sh 公开数据，提供热门 / 趋势 / 飙升三个榜；9 个分类；按安装量、星标、名称、相关度排序；服务端搜索 + 本地兜底。

**解决什么**：不知道社区有什么；skills.sh 全英文、信息密。

**优越点**：
- 不用登录、不用账号。
- 榜单中文摘要直接显示。
- 一键下载到中央库，再装给任意 Agent。
- 每张卡有 GitHub 链接和星标数。

**可拍画面**：市场打开；热门/趋势/飙升切换；分类胶囊；搜索「pdf」→ 36 个结果；点「获取」→「已收录」。

**口播**：不知道装什么？逛一圈市场，看中文摘要就能挑。

---

### 4.13 市场摘要：243 条内置 + 长尾自动概括

**是什么**：热门/趋势/上升榜技能内置中文摘要；冷门技能用抽取、翻译、压缩生成，结果缓存；可选 AI 重写。

**解决什么**：市场卡片全是英文长描述；机翻读不懂。

**优越点**：每条只保留「一句话功能 + 一行适用场景」，不堆废话；冷门技能也不用等大模型。

**可拍画面**：卡片两行摘要；「AI 总结本页」按钮；AI 标记。

**口播**：每个技能两行字，告诉你它能干嘛、什么时候用。

---

### 4.14 GitHub 星标 + 本机调用次数 + 「夯」印章

**是什么**：自动识别技能所属仓库并显示星标；统计本机 Claude Code / OpenCode 的调用次数；星标 ≥ 100,000 盖「夯」章；默认按「星标 + 调用」推荐排序。

**解决什么**：不知道哪个技能真的流行、哪个自己真的常用。

**优越点**：
- 星标是社区认可，调用次数是你自己的真实使用。
- 「夯」章一眼识别超级热门。
- 排序可切换：推荐 / 星标 / 调用 / 名称 / 最近修改。

**可拍画面**：卡片右上角红色「夯」章；星标数；「2 次」调用徽标；排序下拉。

**口播**：社区有多认，你自己用得多不多，一眼就知道。

---

### 4.15 AI 找技能

**是什么**：在设置里配好模型，输入一句需求，AI 从当前市场候选里挑 3–8 个，逐条说明理由。

**解决什么**：知道自己要做什么，但不知道哪个技能能做。

**优越点**：
- 不是泛泛推荐，是从真实候选里选，理由具体。
- 支持 10 家预设 + 任意 OpenAI 兼容接口。
- 可以测试连接、保存 Key；Key 存系统钥匙串。
- 不想用 AI 可以完全关闭。

**可拍画面**：输入「我想把一篇文章做成小红书图文卡片，再配一张封面图」→ 推荐 4 个技能，每条带「适合…」理由；顶部总结「做图文卡片需前端设计+AI配图」。

**口播**：说一句你想干嘛，它把合适的技能挑出来，还告诉你为什么。

---

### 4.16 AI 语义摘要

**是什么**：为市场长尾技能或本机技能生成「功能 + 适用场景」，支持单条和批量，结果缓存。

**解决什么**：129 条覆盖不到的新技能；市场冷门技能没有中文说明。

**优越点**：提示词内置，只输出 JSON；不会把 Key 写进导出配置；批量结果优先显示。

**可拍画面**：市场「AI 总结本页」→ 卡片出现 AI 标记和两行摘要。

**口播**：没有中文说明的技能，让它补上。

---

### 4.17 本地优先与安全

**是什么**：扫描只读；安装/移除只动勾选目录；扫描数据不上传；AI 默认关闭；Key 用系统钥匙串（macOS Keychain / Windows DPAPI / Linux libsecret）。

**解决什么**：不想把技能内容、路径、Key 交给第三方。

**优越点**：
- 无账号、无遥测、无云端依赖（市场/GitHub/AI 之外不发请求）。
- 移除进废纸篓，可恢复。
- Key 不进日志、不进导出配置。

**可拍画面**：设置页「AI 语义摘要（可选）」；Key 输入框显示「已保存，重新输入可替换」；断网时书架照常可用。

**口播**：你的技能留在你电脑里，AI 想开就开，不想开就不开。

---

### 4.18 跨平台

**是什么**：macOS arm64、Windows x64（安装版 + 免安装）、Linux x64/arm64（AppImage + deb）。

**解决什么**：换平台就得换工具。

**优越点**：同一套功能、同一套中文文案；Windows 网络跟随系统代理。

**可拍画面**：三个平台窗口并排（或图标切换）；安装包列表。

**口播**：Mac、Windows、Linux，都有。

## 5. 十条优越性（「为什么是它」章节）

1. **覆盖广**：57 个 Agent 名称、55 个独立目录（含中央库共 56 个目标），国内外 Agent 都覆盖。
2. **中文优先**：129 条人工简介，不是机翻；市场摘要也是中文。
3. **真的合并**：同名技能只占一张卡，标来源、标多版本。
4. **跨 Agent 安装**：一次勾选多个工具，复制/软链随你选。
5. **删除可控**：按 Agent 单独移除，默认进废纸篓。
6. **市场闭环**：榜单 → 中文摘要 → 下载 → 装给任意 Agent，不跳工具。
7. **AI 可选**：10 家模型 + 自定义接口；找技能、写摘要；不用 AI 也完整可用。
8. **本地优先**：扫描不上传、无账号、无遥测；Key 进钥匙串。
9. **工作流沉淀**：套装、项目关联、批量、导入、配置备份。
10. **跨平台**：macOS / Windows / Linux 都有包，核心功能一致。

## 11. 事实边界（避免翻车）

### 可以说

- 50+ 款 Agent（精确说：57 个名称 / 55 个独立目录 / 含中央库 56 个目标）。

- macOS、Windows、Linux arm64 实测；Linux x64 已构建。
- 开源 MIT、软件免费；AI 用你自己的 Key。

### 不要说

- ❌「世界第一 / 唯一 / 永久免费」——无法验证，也容易招黑。
- ❌「支持所有 Agent」——说「50 多款」或「主流 Agent」。
- ❌「Linux x64 已实测」——只实测了 arm64；x64 是构建通过。
- ❌「AI 免费」——模型调用会产生你的 API 费用。
- ❌「绝对安全 / 不会出错」——说「扫描只读、移除进废纸篓、本地优先」。
- ❌ 展示真实 API Key、真实用户名、真实私有技能。

### 需要标注

- 安装包未签名：macOS 首次打开需放行，Windows SmartScreen 需「仍要运行」。
- 市场数据来自 skills.sh，与本项目无隶属关系。

## 12. 评论区 Q&A（可直接复制回复）

**Q：会不会把我原来的技能删了？**
A：不会。扫描只读；移除只作用于你在详情里点的那一个 Agent 的那一份，默认进废纸篓。

**Q：要钱吗？**
A：软件开源免费（MIT）。AI 是可选功能，用你自己的 Key，费用交给模型厂商。

**Q：支持 Windows 吗？**
A：支持，安装版和免安装版都有，Windows 11 x64 实测过。

**Q：支持 Linux 吗？**
A：AppImage 和 deb 都有；arm64 实测过，x64 已构建。

**Q：技能内容会上传吗？**
A：扫描不上传。只有你主动开 AI 时，才会把技能名称和描述发给所选模型。

**Q：和 skills.sh 什么关系？**
A：读它的公开榜单数据，不是官方客户端，也没有隶属关系。

**Q：为什么没签名？**
A：个人项目，证书成本太高；首次打开按提示放行即可。

**Q：能同步到另一台电脑吗？**
A：目前支持配置导出/导入（目录、套装、安装方式），不做云同步。

**Q：AI 支持哪些模型？**
A：DeepSeek、MiniMax、小米 MiMo、智谱 GLM、Kimi、通义千问、硅基流动、OpenRouter、Gemini、OpenAI，以及任意 OpenAI 兼容接口。

**Q：有英文界面吗？**
A：目前界面以中文为主，英文说明在 README 里。
