# 功能清单与设计取舍

技能架的目标不是把「Skills 管理」做成一个大而全的平台，而是把日常最高频的四件事做顺：**找得到、看得懂、装得上、删得掉**。

## 核心能力

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 多 Agent 扫描 | ✅ | 56 个内置工具目录，路径不存在时标记「未检测到」，不会误建目录 |
| 重复技能合并 | ✅ | 按技能名合并，来源徽标 + 「多版本」提示 |
| 中文简介 | ✅ | 129 条人工整理，「功能 / 什么时候用 / 优势 / 注意」四段式 |
| 模糊搜索 | ✅ | 多关键词 AND、包含匹配、子序列匹配、相关度排序 |
| 自动归类 | ✅ | 名称/描述/正文三级加权，自动落入 9 个分类 |
| 复制 / 软链安装 | ✅ | Windows 自动尝试 junction，失败回退复制 |
| 一键移除 | ✅ | 按 Agent 逐个移除，默认进废纸篓 |

## 做得更细的地方

- **推荐排序**：默认按星标与调用次数加权，也可按星标、调用次数、名称、最近修改排序。
- **市场无需账号**：直接读 skills.sh 公开数据，下载走 GitHub 原始文件，不引入登录或服务端。
- **市场摘要**：热门榜内置中文摘要，长尾自动抽取/翻译并缓存，卡片只保留「一句话功能 + 一行适用场景」。
- **自带模型**：用自己的 Key，内置 10 家以上 OpenAI 兼容服务与自定义 URL；提示词内置，Key 存系统钥匙串。
- **零配置启动**：不要求仓库路径、账号、Git 或同步设置。
- **一屏闭环**：搜索 → 详情 → 勾选工具 → 添加，不跳页；右键直接完成常用动作。
- **键盘操作**：`/` 聚焦搜索，`Esc` 关闭，`Enter` 确认。
- **视觉与反馈**：目录式卡片、分类色、进入/退出动画、骨架屏、Toast 倒计时。

## 刻意不做

| 功能 | 原因 |
| --- | --- |
| Git 备份与多设备同步 | 需要 OAuth、冲突合并、快照恢复，是一整套服务；本应用定位是「本机工具」，配置导出足够换机 |
| 账号型市场 / 上传 / 付费 | 需要账号、服务端与内容审核；浏览和下载已通过 skills.sh 公开数据覆盖 |
| Agent 驱动 CLI | 需要发布到 PATH 并维护跨 Agent 协议，会显著增加安装体积与故障面 |
| 托盘 / 自动更新 / 后台常驻 | 与「简单、可预期」的目标冲突，后续可按需再加 |

## 数据位置

- 设置与套装：Electron `userData/settings.json`（macOS：`~/Library/Application Support/Skills Shelf/settings.json`）
- 中央技能库：`~/.skills-manager/skills`
- 星标与调用缓存：`userData/skill-stats.json`（只含仓库、星标、次数，不含会话内容）
- 扫描只读；安装/移除只作用于勾选的目标目录。
