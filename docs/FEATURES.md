# 功能对照：技能架 vs. skills-manager

对照对象：本机 `skills-manager` 1.42.2（`com.agentskills.desktop`）与源码仓库 1.44.0。
结论：**日常 90% 的操作可以用更简单的方式覆盖**；少数重功能（Git 备份/同步、账号型市场、Agent CLI）刻意不做，理由见文末。

## 本应用额外做的

- **星标 + 使用双维度排序**：默认「推荐」按星标与调用次数加权；也可以单独按星标、调用次数、名称或最近修改排序。
- **市场无需账号**：直接读 skills.sh 公开数据，下载走 GitHub 原始文件，不引入登录或服务端。
- **市场检索**：分类胶囊、按安装量/星标/名称/相关度排序、服务端模糊搜索 + 本地兜底。
- **自带大模型**：用户自己的 Key，支持 10 家以上 OpenAI 兼容服务与自定义 URL；提示词内置，结果本地缓存。
- **零配置启动**：不要求仓库路径、账号、Git 或同步设置。
- **自动分类**：不需要手动打标签，新技能直接落进 9 个中文分类。
- **一屏闭环**：搜索 → 详情 → 勾选工具 → 添加，不跳页；右键直接完成常用动作。
- **更细的中文说明**：一句话说明、什么时候用、优势、注意，来自人工整理的简介库。
- **项目/套装/批量都用同一套选择器**：学习一次，到处可用。
- **视觉与交互**：目录式卡片、分类色、退出/进入动画、骨架屏、Toast 倒计时、键盘 `/`、Esc、Enter。

## 刻意不做

| 功能 | 原因 |
| --- | --- |
| Git 备份与多设备同步 | 需要 GitHub OAuth、合并冲突、快照恢复，是一整套服务；本应用定位是「本机工具」，配置导出足够换机 |
| 账号型市场 / 上传 / 付费 | 需要账号、服务端与内容审核；浏览和下载已通过 skills.sh 公开数据覆盖 |
| Agent 驱动 CLI | 需要把 CLI 发布到 PATH 并维护跨 Agent 协议；会显著增加安装体积与故障面 |
| 活动日志 / 托盘 / 自动更新 | 与「简单、可预期」的目标冲突，后续可按需再加 |

## 数据位置

- 设置与套装：Electron `userData/settings.json`（macOS：`~/Library/Application Support/Skills Manager/settings.json`）
- 中央技能库：`~/.skills-manager/skills`
- 星标与调用缓存：`userData/skill-stats.json`（只含仓库、星标、次数，不含会话内容）
- 扫描只读；安装/移除只作用于勾选的目标目录。
